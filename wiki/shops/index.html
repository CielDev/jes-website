Shops

Shops are a great way to earn gold and the heart of the economy. Players run every market, and there are no admin shops.

Shop plot

Shops can only be built on shop plots. Buy a plot with /plot claim, or skip that if you're the mayor, then run /plot set shop. See plots.

Create the shop

  1. Place a chest in the shop plot.
  2. Hold the item you want to sell.
  3. Left-click the chest with it.
  4. Type the price in gold in chat.
  5. Fill the chest with stock.

Good to know

  • Red sign text means the shop is out of stock.
  • A double chest holds more stock.
  • If the shop holds a stack, like 64 planks, a click sells that stack for the listed price.
  • The minimum price is 1g for 64 items.

Shop commands

Look at your shop and use these:

CommandWhat it does
/qs buySwitch to buy mode
/qs sellSwitch to sell mode
/qs price [price]Change the price
/qs sizeChange the bulk amount
/qs staff add [player]Add a shop helper
/qs staff remove [player]Remove a shop helper
/qs staff clearRemove all helpers
