Quarters

Quarters add apartments to towns. Plots cover a whole chunk, while quarters are 3D boxes of any size, each with its own owner and permissions.

Creating a quarter

Only mayors and councillors can create one. Use flint as a wand to pick two positions, and an outline appears while you hold it. No flint? /q wand gives you a free one-time wand.

Run /q create for a simple box, or /q selection add to add more boxes for a custom shape.

Requirements

  1. It must sit entirely inside one town.
  2. No part can reach into the wilderness.
  3. It can't overlap existing quarters.
  4. It must stay within the world's height limits.

If any of these stop being true, for example if the land is unclaimed, the quarter is deleted.

Permissions

Set permissions for residents, nations, allies and outsiders with /q set [actiontype] [permlevel] [true/false]. They override plot permissions. /q trust add gives someone the owner's permissions, except commands.

Quarter types

TypeWhat it does
ApartmentThe default
InnPlayers can use beds inside
StationPlayers can use boats and minecarts inside

Mayors and councillors change the type with /q type [type]. For outsiders to benefit, the quarter must be an embassy: /q toggle embassy.

Selling and buying

Stand inside and run /q sell [price]. Buyers stand inside and run /q claim. Non-residents can only buy embassies, and they lose the quarter if embassy status is removed.
