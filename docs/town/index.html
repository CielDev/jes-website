Town guide

A town is a group of players sharing protected land. These basics are enough to run a small one, and the rest you can pick up as you go.

The essentials

  • Join a town: ask for an invite, or join an open one with /t join <town>. If invited, type /accept or click the chat prompt.
  • Create a town: it costs 64g. Stand where you want it, run /t new <name> and accept. You start with one chunk.
  • Claim land: each chunk costs 16g. Deposit gold with /t deposit <amount>, stand in an unclaimed chunk and run /t claim. See Claiming land.
  • Join a nation: use /n join <name> or accept an invite with /t invite accept <nation>. The capital must be within 5,000 blocks of your homeblock, or another of its towns within 1,500 blocks. The nation must be open or have invited you.

Tip: don't hand new residents a finished house and free gear. People stick around longer when they build up their own progress.

Town permissions

There are four types, all off by default:

  • Build: place blocks.
  • Destroy: break blocks.
  • Switch: use chests, furnaces, levers, hoppers and droppers.
  • Item: use water, lava, buckets, lighters, bone meal, ender pearls and bottles.

Mayors grant them through ranks or by selling plots. They can also be set for allies and outsiders, for example /t set perm ally build on.

Plots

A plot is a chunk inside a town, managed on its own. Only people with claim rights can add land to a town, but residents can buy plots in it. Press F3+G to see chunk borders.

  • /plot fs <price> puts the plot you're standing on up for sale.
  • /plot claim buys it, giving you full permissions there.
  • /plot unclaim gives it up.

Tip: giving plots away can be worth it. Residents leave if they've got nowhere to build.

Plot types

Set one with /plot set <type>. A plot has one type at a time.

TypeWhat it does
DefaultGeneral use, like homes and town bases
ShopRequired for shops
ArenaPvP on, and players keep inventory and XP on death
VaultOnly the mayor and players added with /plot trust add get in
FarmNation residents can harvest crops but not break other blocks, and mobs can be hurt
EmbassyAnyone can buy it, from any town. Handy for overseas shops
InnNon-owners can use beds
WildsStone, ores, deepslate and similar can be broken. Good for public mines

Plot commands

Plot permissions override town permissions.

CommandWhat it does
/plot fs [price]Put the plot up for sale
/plot claimBuy an available plot
/plot unclaimRemove yourself from a plot
/plot set [type]Set the plot type
/plot set [minjoindays/maxjoindays] [number/clear]Reserve plots for new or long-time players
/plot set perm [build/destroy/switch/itemuse]Set plot permissions
/plot toggle [explosion/fire/mobs/pvp]Toggle plot behaviour

Town ranks

Assign them with /t rank add <player> <rank>.

RankWhat it can do
CouncillorFull access to all plots and most town commands, including withdrawing gold. Can't unclaim, change the mayor or delete the town. Give it only to people you really trust
TrustedAccess to any plot, without the advanced commands
BuilderBuild, open chests, use items and break blocks on plots nobody owns
RealtorSell unowned plots and set embassies. Can also evict, sell and manage quarters
SettlerClaim chunks with /t claim
RecruiterInvite players with /t add
PoliceAdd outlaws with /t outlaw add
TreasurerWithdraw from the bank with /t withdraw

Inactivity and succession

Anyone who doesn't log in for 42 days becomes inactive. They stop counting toward town size and don't appear in town and nation lists, but keep their plots, quarters and ranks.

If the mayor goes inactive, the longest-serving councillor takes over. With no councillors, it goes to the most active resident. A town is deleted after 42 days if no resident has logged in.

Town warps

Larger towns can add teleport points with /t warpmanager add <name>. Only your town and nation can use them, with /t warp <town> <name> or /t warp <name> inside your own town.

  • Teleporting is free, but each warp costs the town 1g per day.
  • You need at least 128 chunks, and each extra warp doubles that: 256, 512, 1,024.
  • The maximum is 5 warps.

Merging and ceding

/t merge <town> lets a town absorb a touching town, keeping claims, residents, plots and the bank. It costs 8g per absorbed chunk, and both mayors must agree.

/t cede plot <town> offers one chunk to a neighbouring town for 12g. The other mayor must be online, it must be an edge chunk, and the town must border it.

/t toggle outsiderspawn lets outsiders use your town spawn for 5g per day.
