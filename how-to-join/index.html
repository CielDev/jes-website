How to Join

One address for Java and Bedrock. No mods, no launcher tricks, no nonsense.

Windows, macOS and Linux

  1. Open Minecraft Java Edition on version 26.2.
  2. Click Multiplayer, then Add Server.
  3. Name it whatever you like and enter jes.earth as the address.
  4. Click Done and join the server from your list.

Red X or can't connect? It's usually an outdated game. Check that your launcher is on 26.2.

Windows, mobile and console

  1. Open Minecraft on your device.
  2. Go to Play, open the Servers tab and choose Add Server.
  3. Name it whatever you like and enter jes.earth as the address.
  4. Enter 19132 as the port.
  5. Save it, find it in your server list and join.

On Xbox, PlayStation or Switch? Consoles hide the Add Server option. Ask in our Discord and we'll help you get in.
